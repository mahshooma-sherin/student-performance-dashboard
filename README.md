Student Performance Dashboard

An interactive Excel dashboard designed to monitor and analyze student learning progress, attendance, reviews, and presentation activities.

Dashboard Features
Student profile and identification
Course progress tracking
Current topic tracking
Staff/trainer information
Attendance monitoring
Working days and absent days
Student review tracking
Review marks and status
Presentation tracking
Presentation completion status
Interactive Excel-based reporting
Tools Used
Microsoft Excel
Excel Tables
Power Query
Pivot Tables
Lookup Functions
Excel Formulas
Data Visualization
Dashboard Preview

Project Purpose

The dashboard helps training institutes monitor student performance and maintain important academic information in one place.
